# PortScope

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

TCP ポートごとに、どのプロセスが待ち受けているかを確認できる、軽量な macOS ネイティブのメニューバーアプリです。

## 現在の機能

- macOS の `lsof` ユーティリティを使って TCP の待ち受けポートを一覧表示します。
- 4 秒ごとに更新し、プロセス名、ポート、PID で検索できます。
- 各リスナープロセスの物理メモリ使用量と直近の CPU 使用率を表示し、メモリ、次に CPU の高い順に並べます。メモリが搭載メモリの 10% に達するか、CPU 使用率が 1 コア分の 100% に達すると、値が赤色になります。
- 各行のコンテキストメニューから、エンドポイントや localhost URL をコピーできます。
- 自分のアカウントで実行されているプロセスに `SIGTERM` を送る前に、確認を求めます。
- 停止できるプロセスには淡い背景色を表示します。保護対象のプロセスは通常の背景と鍵のラベルを使い、停止操作を非表示にします。システムの実行ファイル、他のアカウントのプロセス、実行ファイルのパスを確認できないプロセスが保護対象です。
- シグナルを送る直前に PID とエンドポイントを再確認します。管理者権限では実行されません。

初期バージョンには Docker の操作、Kubernetes、Cloudflare、自動終了ルール、強制終了機能は含まれていません。基本的なポート一覧を実際に使った後で、追加を検討できます。

## ビルドと実行

macOS 13 以降と Xcode Command Line Tools が必要です。

```sh
swift run
```

現時点ではソースコードのプロジェクトであり、署名・公証済みのリリースではありません。ビルドしたアプリをパッケージ化して配布すると、macOS が警告を表示する場合があります。未検証のビルドで Gatekeeper を回避しないでください。

# PortScope

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

一款轻量的原生 macOS 菜单栏应用，用于查看哪个进程正在监听各个 TCP 端口。

## 当前功能

- 使用 macOS 的 `lsof` 工具列出 TCP 监听端口。
- 每四秒刷新一次，并支持按进程名称、端口或 PID 搜索。
- 显示监听进程的物理内存占用和近期 CPU 使用率，并按内存、再按 CPU 从高到低排序。当内存达到已安装内存的 10%，或 CPU 达到一个 CPU 核心的 100% 时，数值会变为红色。
- 可通过每一行的右键菜单复制端点和 localhost URL。
- 向属于当前账户的进程发送 `SIGTERM` 前会请求确认。
- 为可以停止的进程显示淡色背景。受保护的进程使用普通背景和锁定标签，并隐藏停止操作。系统可执行文件、其他账户的进程，以及无法识别可执行文件路径的进程均受保护。
- 发送信号前会重新检查 PID 和端点；应用不会以管理员权限运行。

首个版本不包含 Docker 控制、Kubernetes、Cloudflare、自动结束进程规则或强制结束功能。待基础端口列表经过实际使用后，再考虑是否加入这些功能。

## 构建和运行

需要 macOS 13 或更高版本，以及 Xcode Command Line Tools。

```sh
swift run
```

目前这是源代码项目，并非已签名和公证的发行版本。打包并分发构建出的应用时，macOS 可能会显示警告；请勿绕过 Gatekeeper 运行未经验证的构建版本。
